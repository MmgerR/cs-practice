1 коммит:
рабочая папка - папка в которой производится работа с файлами в данный момент
индекс - место где промежуточно хранятся изменённые файлы перед коммитом
коммит - фиксация изменённых файлов
2 коммит:
гит - это система контроля версий, а гитхаб - это платформа для хостинга репозиториев
Использованные команды (3 коммит):
git status - показывает что изменилось с последнего коммита 
git diff - показывает изменения которые ещё не добавлены в индекс
git diff --staged - показывает изменения сохранённые в индекс по сравнению с последним коммитом
Ветки:
ветка - это отдельная линия коммитов. при новом коммиите, о сохраняется в текущей ветке. слияние соединяет новую ветку с основной.
